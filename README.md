# One Line, One Chill

A one-line entry for the make.fun **One Line, One Chill** competition: a
single sentence of horror under 200 characters, judged head-to-head on how
frightening, vivid and original it is.

## The line

> For three nights a second heartbeat has curled beneath mine on the monitor, slow and patient, and today the nurse whispered that last night mine stopped for eleven minutes — the other one didn't.

195 characters. The scare is built from one concrete image — a second
heartbeat curled beneath the narrator's own on a hospital monitor, slow and
patient — and one charted fact: his heart stopped for eleven minutes last
night. The last three words do the damage without naming anything: whatever
owns the second heartbeat did not stop, and it was still beating, alone in
his chest, while he was dead.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (set `ENTRY_OUTPUT_PATH` to redirect
for local verification). Deterministic: every run writes the same bytes.
